##### Instrucciones de ejecución

- Si se quiere ver el flujo del programa desde el inicio, hay que eliminar todos los archivos de las carpetas claves, certs, certs_usuarios, solicitud_certs y las carpetas de nuevoscerts y solicitudes dentro de AC1, además de dejar vacíos los archivos json reservas y usuarios que se encuentran en la base de datos.

- En caso contrario, simplemente ejecutar con normalidad.
